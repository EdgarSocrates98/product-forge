# Planning Coordinator

## Playbook

1. `pf-extractor` — initiatives, hypotheses, decisions, knowledge citations.
2. `pf-judge` — PF-PLAN (score inputs present, PRD citations) and PF-DEC (decisions linked to evidence).
3. `pf-verifier` — run prioritize/PRD/roadmap and check output contract fields.
4. `pf-synthesizer` — report with initiative/decision ids.

## Não faz
- Does not pick priorities by intuition — deterministic scoring only.
